# Задание 1

## Задача 1.2
### Текст задачи
```
Человек.  
Создайте сущность Человек, которая описывается: 
• Имя: строка 
• Рост: целое число 
Может возвращать текстовое представление вида “Name, рост: height”, где Name и height это 
переменная с именем и ростом. 
Необходимо создать и вывести на экран следующих людей: 
• Человек с именем “Клеопатра” и ростом 152 
• Человек с именем “Пушкин ” и ростом 167 
• Человек с именем “Владимир ” и ростом 189
```
### Алгоритм решения
1. Создать класс `Human` с `private` полями `_name` (тип `string`) и `_height` (тип `int`).
2. Реализовать конструктор `Human(string name, int height)`, инициализирующий свойства класса.
3. Реализовать свойства `Name` и `Height`. В `set` свойства `Height` добавить проверку условия `value > 0`. Если условие не выполняется, то использовать цикл `while` и метод `IoHelper.ReadInt` для запроса корректного значения, пока оно не будет введено.
4. Переопределить метод `ToString()`, чтобы он возвращал строку в формате `$"{_name}, рост: {_height}"`.
5. Создать класс `Task1` и метод `ExecuteSubtask2()`.
6. В методе `ExecuteSubtask2()` создать три экземпляра класса `Human`: ("Клеопатра", 152), ("Пушкин", 167) и ("Владимир", 189).
7. Вывести каждый созданный объект в консоль.

## Задача 1.3
### Текст задачи
```
Имена.  
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, 
Отчество. Имя может быть приведено к строковому виду, включающему традиционное 
представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван 
Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может 
быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. 
Необходимо создать следующие имена: 
• Клеопатра 
• Пушкин Александр Сергеевич 
• Маяковский Владимир 
Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в 
образовании строки.
```
### Алгоритм решения
1. Создать класс `Name` с `private` полями `_lastName`, `_firstName` и `_middleName` (тип `string`).
2. Реализовать конструктор `Name(string lastName, string firstName, string middleName)`, инициализирующий свойства класса.
3. Реализовать свойства `LastName`, `FirstName` и `MiddleName`.
4. Переопределить метод `ToString()`. В нем создать пустую строку и последовательно проверять каждое поле на `!string.IsNullOrEmpty`. Если поле не пустое, добавлять его к итоговой строке через пробел. В конце вернуть строку, убирая лишние пробелы с помощью `.Trim()`
5. В классе `Task1` создать метод `ExecuteSubtask3()`.
6. В методе `ExecuteSubtask3()` создать три экземпляра класса `Name`: ("", "Клеопатра", ""), ("Пушкин", "Александр", "Сергеевич") и ("Маяковский", "Владимир", "").
7. Вывести каждый созданный объект в консоль.

# Задание 5

## Задача 5.5
### Текст задачи
```
Дроби.  
Создайте сущность Дробь со следующими особенностями: 
• Имеет числитель: целое число 
• Имеет знаменатель: целое число 
• Дробь может быть создана с указанием числителя и знаменателя  
• Может вернуть строковое представление вида “числитель/знаменатель” 
• Может выполнять операции сложения, вычитания, умножения и деления с другой Дробью 
или целым числом. Результатом операции должна быть новая Дробь (таким образом,обе 
исходные дроби не изменяются) 
Затем необходимо выполнить следующие задачи: 
1. Создать несколько экземпляров дробей. 
2. Написать по одному примеру использования каждого метода. 
3. Вывести на экран примеры и результаты их выполнения в формате «1/3 * 2/3 = 2/9» 
4. Посчитать f1.sum(f2).div(f3).minus(5) 

```
### Алгоритм решения
1. Создать класс `Fraction` с `private` полями `_numerator` (тип `int`) и `_denominator` (тип `int`).
2. Реализовать конструктор `Fraction(int numerator, int denominator)`, инициализирующий свойства.
3. Реализовать свойство `Numerator`.
4. Реализовать свойство `Denominator`. В `set` добавить следующую проверку: если `value == 0`, использовать цикл `while` и `IoHelper.ReadInt` для запроса корректного знаменателя.
5. Реализовать методы `Sum`, `Minus`, `Multiply` и `Div`, каждый из которых имеет две перегрузки. Первая перегрузка должна принимать объект того же типа (Fraction), а вторая принимать целое число `int`.
6. В каждом методе операции создавать и возвращать новый экземпляр класса `Fraction` с вычисленными значениями числителя и знаменателя, не изменяя исходную и передаваемую дробь.
7. Переопределить метод `ToString()`, чтобы он возвращал строку в формате `$"{_numerator}/{_denominator}"`.
8. Создать класс `Task5` и метод `ExecuteSubtask5()`.
9. В методе создать три экземпляра дроби `f1` (1/2), `f2` (1/3), `f3` (2/5).
10. Продемонстрировать работу каждого метода класса `Fraction` с выводом в консоль.
11. Выполнить цепочку вычислений `f1.Sum(f2).Div(f3).Minus(5)` и вывести результат в консоль.
